# MaheshLabs

A podcast by Mahesh Nandigam and Mahesh Moholkar. New episodes every Saturday.

Built with Next.js, React, and TypeScript.

## Development

Requires Node.js 20.9+.

```sh
npm install
npm run dev
```

Open http://localhost:4173.

## Build

```sh
npm run check
npm run build
```

Static output: `out/`.
